WHAT THIS APP DOES (FULL FEATURE LIST)
================================================================

MODULE 1 — JOB APPLICATION TRACKING
- User can add job applications: company, role, status, salary, notes, date applied
- Kanban board: Applied → Interview → Offer → Rejected (drag and drop)
- Edit, delete, search, and filter applications
- 24x7 live tracking — status updates in real time when email replies detected

MODULE 2 — AI RESUME ANALYZER
- User uploads their PDF resume + pastes a job description
- AI returns: match score %, missing skills, strengths found, improvement tips
- Show a detailed report card for each application

MODULE 3 — AI RESUME AUTO-UPDATER (NEW)
- AI reads the job description and user's existing resume
- Automatically rewrites resume bullet points to match job keywords
- Rewrites summary/objective section for that specific job
- Outputs an updated resume the user can download as PDF
- Scores the new resume — shows improvement from old score to new score
- Goal: maximize match score to 85%+ for every application

MODULE 4 — JOB CRACK TIPS (NEW)
- For each job application, AI generates:
  * Top 5 skills to learn before the interview
  * Common interview questions for that role at that company
  * Tips on company culture and what they look for
  * Suggested projects to show in the interview
  * LinkedIn profile improvement tips specific to that role

MODULE 5 — AUTO-APPLY BOT (NEW)
- User sets their job preferences: role, location, salary range, skills, work type
- Bot scrapes job listings from: LinkedIn, Internshala, Naukri, Indeed
- Filters jobs that match user criteria (match score > 70%)
- Auto-fills application forms with user's data
- Selects best matching resume version from vault
- Submits application and logs it in the tracker automatically
- User can set daily apply limit (e.g., max 10 per day)
- Bot runs as a background scheduled job (node-cron)

MODULE 6 — RESUME VAULT (NEW)
- User can store multiple resume versions (e.g., "Frontend Resume", "ML Resume")
- Each resume tagged with skills and roles it targets
- Auto-apply bot picks the best-matched resume per job automatically
- All resumes stored in Cloudinary with version history

MODULE 7 — EMAIL INTELLIGENCE (NEW)
- Connect Gmail or Outlook using OAuth2
- Background job scans inbox every 30 min for job-related emails
- Detects: offer letter, rejection, interview invite, assessment link
- Auto-updates the Kanban board status when email detected
- Sends user a push notification + email alert immediately
- Extracts interview date/time from email and adds to calendar reminder

MODULE 8 — SMART NOTIFICATIONS
- Email reminders: follow up if no reply in 7 days
- Interview day reminder: 24 hours before
- Daily digest: summary of all active applications
- Instant alert when offer/rejection email detected
- SMS notifications via Twilio (optional)

MODULE 9 — ANALYTICS DASHBOARD
- Total applications, interviews, offers, rejections (stat cards)
- Applications per week (line chart)
- Pipeline funnel chart (applied → interview → offer)
- Success rate by company type, role, source
- Average response time per company
- Skills gap chart: most common missing skills across all applications

  DELETE /api/resumes/:id

AI Endpoints:
  POST   /api/ai/analyze           (score + missing skills)
  POST   /api/ai/rewrite-resume    (auto-updated resume)
  POST   /api/ai/job-tips          (crack tips for a job)

Auto-Apply:
  POST   /api/autoapply/start      (start bot for user)
  GET    /api/autoapply/status     (bot running status)
  POST   /api/autoapply/stop
  GET    /api/autoapply/logs

Email Intel:
  POST   /api/email/connect-gmail  (OAuth2 flow)
  GET    /api/email/scan           (manual trigger)
  GET    /api/email/logs

Dashboard:
  GET    /api/dashboard/stats
  GET    /api/dashboard/charts

================================================================
AI SERVICE ENDPOINTS (Python FastAPI)
================================================================

POST /analyze
  Body: { resume_text, job_description }
  Returns: { match_score, missing_skills, strengths, suggestions }

POST /rewrite
  Body: { resume_text, job_description, target_score: 85 }
  Returns: { updated_resume_text, new_score, changes_made[] }

POST /tips
  Body: { job_title, company_name, job_description }
  Returns: { skills_to_learn[], interview_questions[], culture_tips,
             suggested_projects[], linkedin_tips[] }

POST /scrape-jobs
  Body: { role, location, salary_min, skills[], sources[] }
  Returns: { jobs: [{ title, company, url, match_score, jd_text }] }
